# Contributing

Suggestions and fixes are welcome.

1. Describe the problem or proposed improvement clearly.
2. Keep pin assignments and documented behavior synchronized with the code.
3. Test changes on the intended ESP32 board where possible.
4. Record the board model, Arduino-ESP32 core version, wiring changes, and test results.
5. Do not report hardware tests or learning outcomes that were not performed.

For bug reports, include the exact error message, board/core version, the relevant serial output, and steps to reproduce the issue. Do not include passwords, API keys, or other secrets.
